# Contributing

Issues and pull requests are welcome. For anything larger than a small fix, open an issue first so
we can agree on the approach before you write code.

## Setup

Node 20 or later.

```sh
npm ci
npm run check   # lint, format check, type check, tests
```

No API keys are needed. The default config uses the deterministic mock provider, and the OpenAI
and Anthropic adapters are tested against a fake `fetch`.

## Before you open a pull request

Run the same steps CI runs:

```sh
npm run lint
npm run format:check
npm run typecheck
npm test
npm run build
npm run demo
npm run bench && git diff --exit-code bench/results.json
npm run site
```

- Keep tests deterministic and offline. Inject `Clock`, `Sleeper` and `Random` instead of using
  timers or `Math.random` directly, and never call a live model or network service from a test.
- If your change alters routing, pricing, caching or the mock provider, rerun `npm run bench` and
  `npm run chart`, commit `bench/results.json` and `docs/img/frontier.svg`, and update the results
  table, demo transcript and any numbers quoted in `README.md` and `docs/PRODUCT.md`. Tests fail
  when the table, transcript or chart drift from what the code produces.
- Tune routing thresholds on the dev split (`npm run bench -- --split dev`) and report the test
  split. Do not tune on the test split.
- Prompts added to the benchmark must be synthetic and generated by `bench/generate.ts`. Do not
  commit real user prompts or company data.
- Use imperative commit messages that say what changed ("Respect Retry-After in backoff").
